# Boarding Time — Reels

Espace d'hébergement des Reels Boarding Time prêts à publier.

Instagram et Buffer exigent un lien public direct vers la vidéo (Google Drive est refusé). Chaque Reel fini est déposé ici dans `reels/`, puis le scénario Make « Publication réseaux du jour » le publie à l'heure prévue.

- Format : MP4 H.264, 9:16, 30 i/s, moins de 100 Mo
- Nom des fichiers : `AAAA-MM-JJ-sujet.mp4`
- Les vidéos de plus de 2 mois sont supprimées pour rester sous la limite de 1 Go de GitHub Pages.
